# Rennova by Metruminvest

Сайт компании Rennova: ремонт под ключ, дизайн интерьера, архитектура и клининг.
Laravel 13 + Livewire 4, без сборки фронтенда (стили в `public/css/app.css`).

## Что есть

- **Услуги**: клининг, ремонт, дизайн, архитектура и комплексная услуга «Rennova Complete», заявки с сайта.
- **Эксклюзивные бренды**: витрина с фильтрами, бегущая строка на главной. В базе стоят брендов-заглушки, замените их в админке.
- **Обсуждения** дизайна, архитектуры и ремонта для зарегистрированных пользователей.
- **Импорт специальных товаров**: пользователь отправляет запрос и видит статус и ответ менеджера.
- **Аутентификация**: регистрация, вход, профиль, смена пароля.
- **Админпанель** `/admin`: заявки, запросы на импорт, модерация обсуждений, услуги, бренды, пользователи и роли, настройки.
- **Facebook и Instagram**: ссылки задаются в «Админка → Настройки и соцсети» (или переменными `FACEBOOK_URL`, `INSTAGRAM_URL`). Пока ссылки нет, иконка приглушена.
- **Мотивы мировой архитектуры**: линейные SVG Эйфелевой башни, Бурдж-Халифы, Сиднейской оперы, Колизея, Тадж-Махала, Эмпайр-стейт-билдинг, пирамиды Лувра, Биг-Бена и ереванского Каскада (`resources/views/components/landmark.blade.php`).

Брендбук: цвета `#565f49`, `#333929`, `#2e2f2c`, `#5f605e`, `#ecebe1`, шрифт Montserrat.

## Локальный запуск

```bash
composer install
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate --seed
php artisan serve
```

Админ по умолчанию: `admin@rennova.am` / `password` (задайте `ADMIN_EMAIL` и `ADMIN_PASSWORD` в `.env` перед сидированием).

## Деплой на Vercel

Vercel не запускает PHP сам по себе, поэтому используется общественный рантайм
[vercel-php](https://github.com/vercel-community/php) (PHP 8.4), он уже настроен в `vercel.json`.
Файловая система Vercel только для чтения, поэтому нужна внешняя база Postgres (например, Neon из Vercel Marketplace).

1. Импортируйте репозиторий в Vercel (Framework Preset: Other).
2. Добавьте переменные окружения:
   - `APP_KEY` — вывод `php artisan key:generate --show`
   - `APP_URL` — адрес сайта
   - `DB_URL` — строка подключения Postgres (если база Neon подключена через Vercel Storage, подхватится `DATABASE_URL` автоматически)
   - `ADMIN_EMAIL`, `ADMIN_PASSWORD` — первый администратор
   - `SETUP_TOKEN` — длинная случайная строка
3. После деплоя откройте один раз `https://ваш-сайт/setup/<SETUP_TOKEN>`: создадутся таблицы и стартовые данные.
   Затем удалите `SETUP_TOKEN` из переменных, чтобы отключить этот адрес.

Если позже понадобится обычный PHP-хостинг (Forge, Hostinger, VPS), проект работает там без изменений.
